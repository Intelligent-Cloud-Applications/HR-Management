TEKKZYWORK HR MANAGEMENT SYSTEM - DATABASE SCHEMAS & TABLES

Below is a consolidated list of the schemas and suggested database table names required for the application based on the existing frontend data structures (extracted from src/data).

---
1. Table Name: `Employees`
Schema / Structure:
- institutionId (string, Primary Key)
- cognitoId (string, Sort Key)
- employeeCode (string, Unique)
- name (string)
- role (string)
- department (string)
- email (string, Unique)
- phone (string)
- location (string)
- status (enum: "Active" | "On Leave" | "Inactive")
- joiningDate (date/string)
- salary (number)
- avatar (string/URL)
- rating (number)
- manager (string)
- emergencyContactName (string)
- emergencyContactRelation (string)
- emergencyContactPhone (string)
- skills (array of strings / JSON)
- bankAccount (string)
- panNumber (string)

---
2. Table Name: `AttendanceRecords`
Schema / Structure:
- institutionId (string, Primary Key)
- cognitoId (string, Sort Key)
- employeeId (string, FK to Employees)
- employeeName (string)
- avatar (string/URL)
- department (string)
- date (date/string)
- checkIn (time/string)
- checkOut (time/string)
- workHours (string)
- status (enum: "Present" | "Late" | "WFH" | "Absent" | "Half Day")

---
3. Table Name: `Departments`
Schema / Structure:
- institutionId (string, Primary Key)
- cognitoId (string, Sort Key)
- name (string)
- code (string, Unique)
- head (string)
- headAvatar (string/URL)
- headRole (string)
- employeeCount (number)
- annualBudget (number)
- openRoles (number)
- description (string)
- accentColor (string)
- activeProjects (number)

---
4. Table Name: `LeaveRequests`
Schema / Structure:
- institutionId (string, Primary Key)
- cognitoId (string, Sort Key)
- employeeId (string, FK to Employees)
- employeeName (string)
- avatar (string/URL)
- department (string)
- leaveType (enum: "Sick Leave" | "Casual Leave" | "Earned Leave" | "Maternity/Paternity")
- startDate (date/string)
- endDate (date/string)
- days (number)
- reason (text)
- status (enum: "Pending" | "Approved" | "Rejected")
- appliedOn (date/string)

---
5. Table Name: `LeaveBalances`
Schema / Structure:
- institutionId (string, Primary Key)
- cognitoId (string, Sort Key)
- employeeId (string, FK to Employees) -- Required for Database relation
- type (string)
- allocated (number)
- used (number)
- remaining (number)
- color (string)

---
